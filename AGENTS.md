# Flutter app instructions

Use Flutter stable and Dart null safety.

Before coding:
- Read docs/spec.md
- Summarize the relevant requirement
- Propose a short implementation plan

Code style:
- Use feature-first folders
- Use Riverpod for state management
- Keep widgets small and testable
- Avoid business logic inside widgets

Validation:
- Run dart format .
- Run flutter analyze
- Run flutter test
